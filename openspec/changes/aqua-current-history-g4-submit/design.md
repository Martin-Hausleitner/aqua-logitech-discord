## Decision

Retain the verified-paste-gate. Physical testing by the user showed no input reaching the OpenLogi route. Restore the missing official G HUB installation with its existing settings backup, enable its exact disabled updater service and make G HUB the sole dispatcher for this mouse's side buttons. The actual G HUB device view identifies front as G5 and back as G4; older prose naming G4 as front was wrong. Use background LSUIElement launcher apps to preserve the cursor focus. Front posts /button/front and back posts /button/back; the stopping button selects ENTER_FORCE or ENTER_NONE. The installed app's native autoEnterApps capability is staff-only and is not an authorized alternative to the bridge. The public Send It feature requires a spoken send instruction and differs from the requested stop-button workflow.

History discovery accepts the legacy root-level file or exactly one account-scoped history. Missing or multiple candidate accounts are not guessed. Snapshots bind to a history source and preserve the existing stat-keyed cache. A stop detects a newly added transcription/session rather than requiring the overall retained item count to increase. Exactly one new nonempty schema-known transcription, newer than both relevant baselines, is required. Account/source changes and conflicting session/timestamp data suppress Return.

The native helper continues to capture PID/window/editable field/selection before recording and independently verify the exact insertion immediately before PID-targeted Return. A timer, history metadata change, returned action name or healthy endpoint alone is not acceptance.

## Verification

Run the mouse-bridge regression suite and isolated child-process shutdown integration tests. Validate the OpenSpec change. Read the live bridge and recording state before restarting only the existing idle bridge. Inspect the installed OpenLogi binding and running device inventory. Use a local test page that displays Return count and never transmits a form; actual G4 start/stop and spoken text remain a separate live acceptance step.
